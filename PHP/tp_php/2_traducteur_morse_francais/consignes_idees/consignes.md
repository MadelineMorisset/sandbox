# Consignes : Traducteur Morse-Français / Français-Morse

## Phase 1 :

En HTML + PHP, réaliser une page dans laquelle on trouve 2 zones de traduction placées l'une en dessous de l'autre, chacune composée ainsi :

> -   **_titre_** : Morse-Français **OU** Français-Morse
> -   **_zone de texte_** : zone ou l'on saisie le texte à traduire
> -   **_bouton_** : Traduire
